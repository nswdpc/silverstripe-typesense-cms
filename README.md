# Typesense integration with Silverstripe CMS module

Provides a page and a controller with a form to handle a search and display the results

### Usage

1. [Documentation](./docs/en/001_index.md)
1. Create a search page
1. Configure the page on the Typesense tab
1. Save / publish

## Installation

```sh
composer require nswdpc/silverstripe-typesense-cms
```
